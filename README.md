# Quick Ping HUD

A small always-on-top window that shows ping to several servers,
download/upload speed, packet loss and your public IP.

## Download
Go to the [Releases page](../../releases/latest) and download **QuickPingHUD.exe**.
Double-click to run. No install needed.

## Windows warning
Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**.
The full source code is in this repository.

## Features
- Ping to multiple IPs with custom names
- Live download/upload speed
- Packet loss and public IP
